# سامانه آموزشی هوش مصنوعی پزشکی

این پروژه یک وب‌سایت آموزشی با Python و Flask است که یک مدل Logistic Regression را روی مجموعه‌داده عمومی Wisconsin Diagnostic Breast Cancer (موجود در scikit-learn) آموزش می‌دهد. برای فرم، ۱۰ ویژگی عددی از مجموعه‌داده استفاده شده‌اند.

## اجرای سریع در ویندوز
فایل `run.bat` را دو بار کلیک کنید. این فایل محیط مجازی می‌سازد، کتابخانه‌ها را از پوشه‌ی `wheels` (بدون نیاز به اینترنت) نصب می‌کند و برنامه را اجرا می‌کند. پوشه‌ی `wheels` فقط برای **Python 3.14 (64-bit) در ویندوز** آماده شده؛ با نسخه‌ی دیگر، برنامه به‌طور خودکار نصب آنلاین را امتحان می‌کند. فایل گزارش دانشگاهی با نام `university_report.docx` در همین پوشه است.

## هشدار مهم
این پروژه صرفاً آموزشی و نمایشی است. خروجی آن تشخیص پزشکی نیست، برای تصمیم درمانی مناسب نیست و نباید برای بیمار واقعی استفاده شود. مدل فقط روی یک مجموعه‌داده عمومی آموزش دیده و اعتبارسنجی بالینی نشده است. اعداد احتمال، احتمال‌های خروجی مدل‌اند و لزوماً احتمال واقعی بیماری نیستند. در صورت نگرانی پزشکی با متخصص سلامت مشورت کنید.

## نیازمندی‌ها
- Python 3.10 یا جدیدتر
- pip

## نصب و اجرا در Windows
1. فایل ZIP را استخراج کنید.
2. در پوشه `medical_ai_project` پنجره ترمینال باز کنید.
3. محیط مجازی بسازید:
   ```bash
   py -m venv .venv
   ```
4. محیط را فعال کنید:
   ```bash
   .venv\Scripts\activate
   ```
5. وابستگی‌ها را نصب کنید:
   ```bash
   python -m pip install -r requirements.txt
   ```
6. برنامه را اجرا کنید:
   ```bash
   python app.py
   ```
7. نشانی `http://127.0.0.1:5000` را در مرورگر باز کنید.

حالت debug به‌صورت پیش‌فرض **خاموش** است. برای فعال‌سازی محلی (در ویندوز CMD): `set FLASK_DEBUG=1` و در Linux/macOS: `export FLASK_DEBUG=1`، سپس `python app.py`.

## اجرا در Linux / macOS
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

## آزمون خودکار و ارزیابی مدل
```bash
python -m unittest discover -s tests -v   # اجرای آزمون‌های خودکار
python evaluate.py                        # چاپ ماتریس درهم‌ریختگی، precision، recall، F1 و اعتبارسنجی ۵-بخشی
```

## ورودی‌ها
ده ویژگی آماری از نمونه بافت، از جمله شعاع میانگین، بافت، محیط، مساحت و ویژگی‌های هندسی. زیر هر فیلد بازه‌ی مقادیر داده‌ی آموزشی نمایش داده می‌شود و دو دکمه‌ی «نمونه‌ی خوش‌خیم» و «نمونه‌ی بدخیم» فرم را با ردیف‌های واقعی مجموعه‌داده پر می‌کنند. اگر مقداری خارج از بازه‌ی آموزشی باشد، هشدار نمایش داده می‌شود (ولی خروجی مسدود نمی‌شود). برای استفاده واقعی باید مقادیر را از منبع آزمایشگاهی معتبر و با همان تعریف و واحد داده‌ها دریافت کرد. این وب‌سایت عمداً هیچ داده بیمار را ذخیره نمی‌کند.

## ساختار پروژه
- `app.py`: مسیر وب، دریافت و اعتبارسنجی فرم، هشدار خارج از بازه
- `data/breast_cancer.csv`: مجموعه‌داده (۵۶۹ ردیف، توضیحات در `data/README.md`)
- `model.py`: بارگذاری داده از فایل CSV، آموزش مدل، معیارهای ارزیابی، بازه‌ی ویژگی‌ها و نمونه‌های مثال
- `evaluate.py`: چاپ معیارهای ارزیابی مدل برای استفاده در گزارش
- `tests/test_app.py`: آزمون‌های خودکار (unittest)
- `templates/index.html`: صفحه وب فارسی
- `static/style.css`: طراحی واکنش‌گرا
- `requirements.txt`: کتابخانه‌های موردنیاز
- `university_report.docx`: گزارش قابل ویرایش دانشگاهی

## محدودیت‌ها
- داده‌ها عمومی و مربوط به یک مسئله مشخص در پاتولوژی پستان هستند؛ این سامانه علائم عمومی بیماری‌ها را تحلیل نمی‌کند.
- دقت آزمون فقط یک ارزیابی ساده روی یک تقسیم‌بندی داده است و معادل اعتبارسنجی بالینی نیست.
- مدل در زمان راه‌اندازی برنامه در حافظه آموزش داده می‌شود؛ این انتخاب برای سادگی پروژه آموزشی است.
- سرور توسعه Flask و `debug=True` فقط برای کار محلی است. قبل از هرگونه استقرار، امنیت، حریم خصوصی، اعتبارسنجی، پایش و الزامات قانونی باید توسط متخصصان بررسی شود.
